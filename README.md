# Tadawul Data Platform

A data engineering and data science training project built around
data from the Saudi Exchange (Tadawul).

## Objective

Build an end-to-end data platform that demonstrates:

- data ingestion
- raw data preservation
- data transformation
- data modeling
- data quality
- lineage
- analytics
- data science

The project is inspired by the architecture and engineering principles
used in the Jassas Data Platform.
